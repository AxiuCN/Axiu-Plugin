# 模块：入群审核、代发言、插件帮助

本文件是 Axiu-Plugin 的详细文档。**规范与铁律在仓库根 `AGENTS.md`**（约定、配置写入口径、测试约定）；这里放事实与实现细节，改对应模块前按需阅读。

### 1. autoGroupApprove — 自动入群审核

- 事件：`request.group.add`，通过 `accept()` 处理
- 流程：提取申请备注中的"答案：xxx" → 匹配黑白名单 → 同意/拒绝/通知管理员
- 机器人无管理员权限时 @通知管理员人工处理
- `checkBotIsAdmin()` 优先 `pickMember().getInfo()`，失败时降级 `getMemberMap()`

### 2. proxySpeak — 代发言

- 命令：`#代@某人 消息内容` 或 `#代QQ号 消息内容`（仅 master，仅群聊）
- 构造假事件（覆盖 `user_id`、`sender`、`member`、`message`、`raw_message`），清除 CD，注入 `loader.deal(fakeEvent)` 重新走插件匹配
- 假消息数组第一个 segment 为 `@机器人`，确保通过 `onlyReplyAt` 检测

### 11. 插件帮助

帮助图命令，参考 LinkFlow-Plugin 的实现。

**文件**：

| 文件 | 职责 |
|------|------|
| `apps/help.js` | 命令入口：`#Axiu帮助` / `#阿修帮助`，按权限过滤 master 分组，渲染帮助图 |
| `resources/help/help-cfg.js` | 帮助内容（`helpCfg` 标题 + `helpList` 分组，分组可带 `auth:'master'` 标记） |
| `resources/help/index.html` | 帮助模板（head-box + 3 列 help-table） |
| `resources/help/index.css` | 帮助样式（深色风格，背景图 + `#12122a` 兜底） |
| `components/pluginVersion.js` | 插件/Yunzai 版本号读取（副标题与版权行使用） |

**数据流**：

```
用户 #Axiu帮助
  → help() 带时间戳动态 import help-cfg.js（?t=${Date.now()}，修改即时生效）
  → 过滤 auth:'master' 分组（非 master 跳过）
  → render('help', 'index', data, 'jpeg')
  → e.reply(img)
```

**要点**：
- 命令正则 `/^#(axiu|Axiu|阿修)(帮助|菜单|指令|命令|help)$/i`，priority 500
- 副标题 `阿修插件 v{version}`，版权行 `Created By TRSS-yunzai v{yunzaiVersion} & Axiu-Plugin v{version}`，版本号来自 `components/pluginVersion.js`（分别读 bot 根目录与插件 `package.json`）
- 背景图 `resources/images/background.png`（`100% auto` 宽度撑满、高度按比例），容器兜底色 `#12122a`
- 帮助内容（help-cfg.js）改动即时生效无需重启；`apps/help.js` 结构改动需热重载

**锅巴图标**：`guoba/index.js` 的 `pluginInfo.iconPath` 指向 `resources/images/Axiu.ico`，锅巴后台插件列表显示该图标。
