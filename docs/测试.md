# 测试

> 本册由插件根 `AGENTS.md` 的「测试」一节拆出，主文件只留命令与摘要。
> **逐套覆盖清单只在 [`../test/README.md`](../test/README.md) 维护**，本册不再抄一份——两份手抄表迟早漂移。改动套件时同步那一处。

## 运行

```bash
cd app/plugins/Axiu-Plugin
pnpm test                          # = node test/run.mjs，跑全部
node test/run.mjs --list           # 只列套件
node test/run.mjs --filter=signin  # 只跑文件名含 signin 的
node test/member-name.test.mjs     # 单跑（任意 cwd 均可）
```

不启动 bot，直接跑真实生产代码路径；每套末尾输出 `结果：通过 N / 失败 N`，`run.mjs` 最后给汇总，**任一失败即 exit 1**。

`run.mjs` 把每个套件的子进程 cwd 钉在 `app/`（部分 model 按 cwd 解析插件内路径），所以**任意 cwd 都能跑**。

## 前置与跳过

**缺前置时打印「⏭ 跳过：原因」并以 0 退出**（不算失败）。所以新克隆的仓库一跑全绿不一定是真绿，先看汇总里的跳过数。

| 前置 | 影响套件 | 缺了怎么补 |
|---|---|---|
| Python 解释器（`AXIU_TEST_PYTHON` 可指定，否则探测 `python` / `python3`） | `signin-runner-marks.test.mjs` | 装 Python，或设 `AXIU_TEST_PYTHON` 指向解释器 |
| `plugins/genshin`（`model/mys/mysSrApi.js`） | `sr-device-timeout.test.mjs` | 恢复 genshin 插件目录 |
| `model/srGacha.js` | `srGacha-merge.test.mjs` | 完整克隆仓库（不要只拷子目录） |
| `defSet/config.yaml` + `config/*.example` | `guoba-write.test.mjs` | 同上 |
| bot 根 `node_modules` 里的 `art-template`（与生产同一份） | `challenge-template.test.mjs` | `cd app && pnpm i` |

其余套件无外部前置：框架全局（`logger` / `redis` / `segment` / `Bot`）用 `test/_helper.mjs` 的**内存桩**，不联网、不触真实 Redis；渲染类套件也不启浏览器（`challenge-template` 只做 art-template 编译，不出图）。

## 规范

| 要求 | 说明 |
|---|---|
| 命名 | `<主题>.test.mjs`，主题写被测行为（如 `rank-order`、`member-name`），不用 `check-` / `stage` 之类历史前缀 |
| 路径 | 一律经 `test/_helper.mjs` 的 `pluginRoot` / `appRoot` / `tmpDir` / `mod()` / `importMod()` 推导，**禁止裸相对字面量与盘符** |
| 前置 | 用 `requireFile()` / `skip()`，不要 `throw`（抛错会被记成失败） |
| 断言 | 用 `checker()`（`check(名称, 条件, 附加信息)` + `finish()`）；数量不必多，但**必须能真的失败** |
| 临时产物 | 只写 `test/.test-tmp/`（已 gitignore）；配置类套件经 `AXIU_CONFIG_DIR` 重定向到该目录，不碰仓库的 `config/` |
| 桩 | 框架全局桩已收敛在 `_helper.mjs`，套件内不要重复实现；需要制造并发交错的用桩的钩子（`beforeWrite` / `beforeZAdd` / `beforeDel`） |
| 数据依赖 | 不写死角色名与条目数；需要真数据时用固定夹具（`test/fixtures/`）或本地样例 |

```js
// test/<主题>.test.mjs 骨架
import { checker, importMod, installFrameworkStubs } from './_helper.mjs'

installFrameworkStubs()                       // 必须在 import 生产模块之前

const { someExport } = await importMod('components/xxx.js')
const { check, finish } = checker()

check('某行为符合预期', someExport(sample) === expected)
finish()                                      // 有失败即 exit 1
```

**新增套件的验收口径**：先临时还原被修的代码，确认断言转红，再恢复后入库——否则无法证明这条断言在守护什么。
