# 配置加载与三层结构

本文件是 Axiu-Plugin 的详细文档。**规范与铁律在仓库根 `AGENTS.md`**（约定、配置写入口径、测试约定）；这里放事实与实现细节，改对应模块前按需阅读。

## 配置加载

### 入群审核配置
- **路径**：`config/group_config.yaml`，由 `getGroupApproveConfig(pluginRoot)` 加载
- **优先级**：`config/group_config.yaml` > `config/group_config.yaml.example` > 空 Map
- **首次启动**：自动从 `.example` 复制
- **锅巴读写**：读侧 `groupsToPanel()` 把两种格式都转成面板行；写侧 `groupsFromPanel()` **保持文件原有形态**（原来是映射就写映射、是数组就写数组）。非数组输入、或整份规则里没有有效群号时**拒绝保存**（不许静默清成 `groups: []`），被跳过的空行在回执里说明

### 主配置（三层结构）

| 文件 | 用途 | 说明 |
|------|------|------|
| `defSet/config.yaml` | 锅巴保存模板 | 值写成 `${变量}` 占位符；**只读输入**，改配置键就改它 |
| `config/config.yaml` | 运行时配置 | 不纳入 git，由锅巴写入或用户手动编辑 |
| `config/config.yaml.example` | 参考默认值 | 纳入 git，具体默认值，首次启动复制到 `config.yaml` |

- **读取（插件侧）**：`Cfg.getConfig('config')` 直接读 `config.yaml`（不合并 defSet 模板），解析失败回退默认值并记 warn；`getPluginConfig()`（`components/config.js`）读同一份文件，不存在时从 `.example` 复制
- **读取（锅巴侧）**：`readConfigWithStatus()` —— 读的是**文件当前内容**（不是模块加载那一刻的快照），并把「读不出来（语法坏掉）」与「本来就没配」分开返回，面板取值与保存回执都按它走

### 群配置双格式兼容

`normalizeGroupConfig()` 同时支持：
- **列表格式**（锅巴 GSubForm）：`groups: [{groupId, whitelistAnswers, blacklistAnswers}]`
- **映射格式**（手动编辑）：`groups: {"123": {whitelistAnswers: [...], blacklistAnswers: [...]}}`

## 写入路径

配置**写入**（锅巴面板保存）的铁律在仓库根 `AGENTS.md` 的「配置写入口径」一节：值一律经 `yamlValue()` 序列化、写盘前 `validateRendered()` 逐键验证、`writeConfigAtomic()` 原子替换、表单没提交的键沿用文件当前值、读不出来时允许救回但回执要点明。本文件只描述**读**路径与文件形态。

`components/config.js` 里与本文件相关的入口：`resolveConfigPath()` / `resolveExamplePath()`（读写同源，`AXIU_CONFIG_DIR` 可重定向，回归套件用）、`readConfigWithStatus()`、`getPluginConfig()`。相关回归见 `test/guoba-write.test.mjs`。
